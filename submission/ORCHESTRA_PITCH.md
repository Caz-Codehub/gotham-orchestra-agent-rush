# Gotham Orchestra — Proof Before Permission

## One-line pitch

A human-governed, multi-orchestra agent command center on Vultr that delegates engineering and security work to specialist AI teams—and proves execution inside disposable Docker sandboxes before approval.

## Hackathon demo (90 seconds)

1. Show the four orchestra groups and separate commanders on `/orchestra` (public page). Explain Software, Research, Cyber Defense and Authorized Security Lab; each is bounded analysis in this MVP.
2. Show the Software Orchestra planning an authorized code fix (authenticated). Separate captain, three specialist reports, Alfred's synthesis and audited events.
3. Navigate to `/` and choose Code Repair → Load Sample. Show baseline failing, candidate passing in network-disabled Docker, Specter receipt, and SHA-256 output.
4. Run `Containment probe`; infinite loop must exit with timeout 124 and container cleanup true.
5. Conclude: Model outputs cannot approve themselves; missing sandbox evidence means no verification. Batman remains the authorization authority and Specter audits independently.

## Submission limits

- Four orchestras are real bounded AI workflows, not four continuously deployed independent model fleets.
- External web research, arbitrary notebook generation, client penetration testing and malware execution are NOT implemented here.
- Public interface needs private token for actions. Show readiness and real receipts, not hidden secrets.
