# Gotham 2.2 — Batman's $0 laptop launch card (Windows 11)

**Your machine:** Core Ultra 7 255H, 16 GB shared system RAM, Intel Arc integrated graphics. Choose the small `qwen2.5:1.5b` model first. Larger models are not needed to prove seven-role orchestration.

**Before launching, install:**

1. Python 3.11 or newer from https://www.python.org/downloads/windows/ (check **Add Python to PATH** if offered). Confirm `python --version` in PowerShell.
2. Local Ollama from https://ollama.com/download/windows . Open it from Windows Start.
3. In PowerShell run: `ollama pull qwen2.5:1.5b`. This downloads free model weights; it is not a hosted-compute fee.
4. For extra certainty, disable Ollama cloud features using `OLLAMA_NO_CLOUD=1` as a *Windows user environment variable*, then fully quit and relaunch Ollama. Official steps: https://docs.ollama.com/faq . Cloud-model aliases are also rejected by Gotham.

**Start Gotham:** Double-click `START_GOTHAM_LOCAL.cmd`, or run the equivalent command from the extracted Gotham folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start_windows.ps1 -Mode ollama
```

The launcher installs local Python packages if missing (internet may be used to download packages), verifies the model, and shows `http://127.0.0.1:8000`. Open that URL on your laptop. Copy the **mission token** into Gotham's mission field and the separate **Batman token** into Specter's audit field. Never send either token to a chatbot or screenshot.

**Test real Qwen agents, with no Docker required:** From a **second** PowerShell window in the project folder, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prove_local_windows.ps1
```

It runs an invented student task manager objective through Alfred and all five agent roles, then checks Specter's audit journal. This uses the local model only and creates a JSON report in `%LOCALAPPDATA%\GothamProject\proofs`. It does **not** visit websites, edit real files, run code generated by the model, or prove quality comparable to Claude. Real Docker code-repair testing remains a later phase.

**Protect schoolwork:** The local engine serializes completions so the seven roles do not multiply the Qwen model weights. It caps each request's context at 4,096 tokens by default and allows the model to unload after 30 seconds idle. Close the Gotham PowerShell window with Ctrl+C to stop the web app. In another PowerShell window, use `ollama stop qwen2.5:1.5b` to free model memory immediately if required. No overnight process is expected.

**Expense rule:** zero cloud VM deployments, zero paid model API calls, and no credit-card steps. Electricity, internet and disk usage are normal local-computing expenses. Local FastAPI binds to `127.0.0.1`, not the public internet.

**Full goal:** Batman gives orders; Alfred supervises five worker agents; Specter independently audits all six and reports only to Batman. This test proves a bounded, local, analysis-only cycle—not seven frontier-class models or 24/7 autonomous operations.
